## O que é

Um kit gratuito para quem aprende inteligência artificial e quer experimentar prestar seu primeiro serviço. Você escolhe um tipo de cliente, demonstra uma melhoria pequena, conversa com o responsável e mede a entrega antes de propor o próximo trabalho. Os modelos ajudam a começar com escopo claro. Você precisa de uma ferramenta de IA que saiba usar e disposição para conversar com um negócio; não precisa instalar este kit.

## Como usar

Abra o guia e siga os quatro passos. Baixe o ZIP, preencha as fichas e abra as planilhas CSV no seu editor. Exemplos de oficina são hipotéticos. Modelos e planilhas em português.

## Escopo

Material educativo. Não é software de prospecção, não envia mensagens e não garante cliente ou renda. Origem e limites em [FONTE.md](FONTE.md). Versão1.0.0.
